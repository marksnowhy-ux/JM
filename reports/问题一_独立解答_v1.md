# 问题一 · 独立解答单元 v1

**单元名**：数据质量评价与配比响应面 ｜ **脚本集**：p0, p1, p2, p3, p14（+p18 冲突/外推部分, p19 参数敏感性部分）｜ **数据域**：`A_data_value/`（全部）

---

## 1. 问题分析（本单元内独立成立）

目标：① 将 22 项数据质量指标归并为可用质量度量，对 7 个质量域给出可靠评分；② 建立训练配比 p 到验证损失的响应面，用于配比优化。

关键难点与本单元的独立决策：
- 8 项列表型指标需标量化；22 项指标方向不一（6 项负向）；指标间存在**质量冲突**（赛题要求定义并消解）；
- A1 为同源抽样（10,000 条/域）、A2/A3 为全量扩展，二者的关系需验证而非假设；
- 17 个配方域 vs 13 个验证域、6 个 direct/near_direct 域映射——配比到质量域映射不完整，需显式处理；
- est_10b/est_70b 为外推非实测（数据说明标注），只能用于稳健性讨论。

## 2. 解决方案设计

- **标量化与方向统一**：列表指标取均值（fineweb_edu 二值列表均值即通过率，语义可解释）；6 项负向指标取负 → 全部"越高越好"；
- **异常值**：IQR/Z-score(±3)/MAD 三法检测 + 缩尾截断（1%/99%；不删样本——book 域仅 171 条，删除损害小样本域）；顺序=先异常处理→再填补→后标准化；
- **缺失值**：两级回退填补（域中位数→全局中位数）；
- **冲突定义与消解**：冲突度 c = 内容质量族均值（10 项）− 规范清洁族均值（6 项对齐后），|c|>1σ 判冲突；消解规则 q* = q_all22 − λ·max(|c|−τ, 0)（主链 λ=0.5, τ=1.0）；
- **响应面**：Elastic Net，特征 = 17 配比一阶 + 153 二次交互；5 折 KFold × 180 组网格选超参；
- **配比单纯形**：行归一化 + 和≈1 断言。

## 3. 实施步骤

p0 探查 → p1 全量流式预处理（272,505 条，lzma 逐行）→ p2 拟合与评估 → p3 域级汇总 → p14 异常值方法学对比 → p18 冲突消解 + est 外推稳健性 → p19 冲突参数敏感性。配置（preprocess/enet）与日志全程版本化 `_v1`。

## 4. 验证环节

- **检验集**：A6–A11 test_1m（256 新配方）R²=+0.639；CV R²=+0.739；
- **抽样 vs 全量对照**：A1 与 A2/A3 id 100% 重叠证实同源；域评分差 < 1 个标准误；
- **异常值影响量化**：四条流水线全链对比——不处理 vs 主链 test R² 仅 −0.0024，但 Q(p) 均值 +0.179→+0.047（异常值主要抬高锚定而非拟合精度）；
- **冲突扩展集检验**：arxiv 抽样率 32.2% vs 全量 34.5%、github 7.5% vs 7.8%（差异均 <2SE）；
- **参数稳健性**：λ∈{0,0.25,0.5,1.0}×τ∈{0.5,1.0,1.5} 全网格域排序 Spearman=1.0000。

## 5. 解答结果

7 域评分（q_all22）：c4 +0.228 > commoncrawl +0.103 > github +0.004 > book −0.002 > arxiv −0.090 > wikipedia −0.067 > stackexchange −0.187；总冲突率 11.8%（book 域最高 80.1%）；est 外推下 1M 配比排序不可直接外推（排序反转，归因于外推表规模属性：同配比 1M 实测 vs est Spearman=−0.74/−0.81）。
