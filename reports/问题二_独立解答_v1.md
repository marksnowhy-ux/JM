# 问题二 · 独立解答单元 v1

**单元名**：广义标度律 ｜ **脚本集**：p4, p5, p6, p7（+p15 敏感性, p18 大模型外推/替代条件部分）｜ **自有数据域**：`B_scaling_laws/`

---

## 1. 问题分析（本单元内独立成立）

目标：建立含参数规模 N、数据量 D、数据质量 Q、领域配比 p 的广义标度律，并按数据可信度分级讨论外推。

关键难点与本单元的独立决策：
- 不同来源的 Loss 不可直接比较（验证集/分词器不同）——验证策略必须区分"形状迁移"与"水平迁移"；
- B6–B8 为半合成数据：质量效应参数不能污染真实律，也不能宣称因果识别；
- B10 为估算 Loss：仅可作一致性检查；B9 为真实大模型元数据：用于外推支撑域讨论。

## 2. 解决方案设计

- **经典律**：L₀(N,D)=E+A·N^(−α)+B·D^(−β)（N,D 以 B 计），线性/对数空间双拟合 + 多起点；
- **质量项（锚定拟合）**：冻结 (E,α,β,B)，仅用 B6 估计质量通道；候选 M1–M4 经 GroupKFold(5)（按 (N,D) 网格分组防泄漏）+ AICc 选型，胜出 M2：L = L₀ + θ_Q·(Q₀−Q)·(D/100)^(−γ)；
- **配方项**：Δ_p(p)·(N/10⁶)^δ，δ 由 1M/60M/1B 三规模效应幅度幂律概括（已声明"仅量级口径"，1B 为独立配方集）；
- **机制诊断**：B8 与 B6 的相容性检验（加性偏移 vs 乘性 E）。

## 3. 实施步骤

p4 探查 → p5 经典律主拟合 + B2–B5 验证 → p6 锚定质量拟合 + 自由拟合漂移检查 → p7 配方 N-标度 → p15 敏感性/算法/文献对比 → p18 大模型外推阶梯 + 替代条件。

## 4. 验证环节

- B1 主拟合：R²=1.0000，RMSE≈1e-4（**伪精度注记**：平滑轨迹，Jacobian SE 不作统计推断）；
- 形状迁移：B4 跨族 12 族仿射校准后 R²=0.951、Spearman=0.983；B5 文献 R²=0.824（近无偏）；B2 验证集口径不同仅部分迁移（诚实标注）；
- 锚定必要性：B6 自由联合拟合使 A 漂移 +53% → 锚定策略被证据支持；
- 质量项：5 折分组 CV RMSE 0.0752 vs 无质量基线 0.2170；B7 独立验证 r²=0.955；
- B8 不相容（Loss 低于 E 下限）→ 乘性机制 r²=0.958，不并入主律仅作量级参考；
- B9 阶梯（132 个 100B–10,000B 真实模型）+ B10 同律一致性（Spearman=1.000）。

## 5. 解答结果

L₀ = 1.69 + 0.354·N^(−0.34) + 1.24·D^(−0.28)（换算原始单位后与 Hoffmann 2022 逐项吻合：α=0.340/β=0.280/E=1.69）；质量项 θ_Q=0.363, Q₀≈1.002, γ=0.041（Q=1 退化近似成立）；配方项 δ≈−0.23；**替代条件**：ΔN = θ_Q·ΔQ·(D/10¹¹)^(−γ)·N^(α+1)/(αA)——D=100B 时 Q+0.1 等价于参数 +17%@0.19B → +144%@100B（质量相对价值随规模递增）；领域交互（ENet）：互补 Top=freelaw×stackexchange（−0.028），替代 Top=pubmed_central×pubmed_abstracts（+0.030，同源族）。
