## 二、五项改进：方法、实施与量化结果

### p30 — Q1 打分引擎升级（组级 CRITIC + 冲突阈值 + Huber）

**方法**：在统一方案口径（softmax 标量表 + 冻结 A1 ECDF + 15 指标 5 组）上：
- **组级 CRITIC**：w_g ∝ 对比强度（组分的域间标准差）× 冲突性（Σ(1−r)，文档级组分数相关），A1 冻结。权重：reason 0.347 > edu 0.197 ≈ read 0.187 > clean 0.134 ≈ struct 0.135——reason 组（modernbert_reasoning/professionalism）区分度最高（0.229）且信息冗余最低，等权方案低估了它。
- **冲突指数**：CI_i = sqrt(Σ_g w_g·(G_ig−q_i)²)，阈值 = A1 分布 IQR 上栅栏 0.3411（数据驱动，不主观指定）；A1 冲突率 0.76%（1329 文档），P90 对照阈值下 7.91%。
- **Huber 稳健重打分**：冲突样本用加权 Huber M-估计位置（IRLS 向量化），位移 mean −0.003、max 0.198；普通样本保留加权均值——降低极端组分数影响且不删除信息。

**实施中发现并修正的问题**：初版在 min–max 尺度上做指标级 CRITIC，验证发现其受离群值驱动，Q→loss 链接方向反转（+0.60，期望负向）——被验证流程拦截后改回 ECDF 秩尺度；指标级 CRITIC 亦劣于组级（struct 8 指标冗余拖偏）。**这本身就是测试流程价值的体现**。

**量化结果**：

| 指标 | v1/v2 基线 | v3 | 变化 |
|---|---|---|---|
| Q-域均loss 链接 Spearman（6 观测域） | −0.371 | **−0.714** | ×1.92 |
| Q-域均loss 链接 Pearson | −0.490 | **−0.656** | +34% |
| Q_star 反向校验 Spearman（13 域） | −0.478 | **−0.731** | +53% |
| 与 v1 域分排序一致性 | — | +0.929 | 稳定演进 |
| A1 vs A2/A3 全量最大偏差 | 0.0010 | 0.0013 | 同量级 |
| 消融：同尺度等权 → CRITIC | −0.371 | −0.714 | 增量 −0.343 全部来自赋权 |

**架构决策**：Huber 修正对域级分数影响很小（冲突率 0.76%），其价值在文档级鲁棒性与论文方法完整性；CRITIC 赋权是链接提升的唯来源（消融证实）。

### p31 — Q2 可靠性层（bootstrap + 退化一致性 + 弹性区间）

**方法**：B6 行级重抽样 500 次重拟合锚定 M2（θ_Q, Q0, γ）；自由联合 8 参数 200 次对照；退化一致性数值验证；代表点（N=1B, D=100B, Q=0.7）弹性与等效替代解析式随 bootstrap 传播。

**量化结果**：

| 量 | 点估计 | bootstrap 95% CI | 符号稳定率 |
|---|---|---|---|
| θ_Q | 0.3627 | [0.338, 0.390] | 100% |
| γ | 0.0412 | [0.008, 0.070] | 98.8% |
| η_N / η_D / η_Q | −0.048 / −0.040 / −0.102 | (见 csv) | — |
| 质量+0.1 ≈ 参数增幅 | **+37.4%** | [+34.4%, +41.0%] | 100% |

- **退化一致性**：Q=Q0 且 Δp=0 时广义律精确退化为经典律（max 误差 0.00e+00，M4 同）——第二套提示词的模型合法性条件首次被形式化验证。
- **自由联合对照**：θ_Q/Q0/γ/E/B/β 的 CI 均覆盖锚定值；A 与 α 不覆盖（半合成 B6 对经典参数识别力有限）——为主律锚定策略（B1 真实数据定经典参数、B6 只识别质量项）提供了 bootstrap 证据，可直接写入论文。
- 弹性结论：代表点质量弹性（|η_Q|=0.102）约为规模弹性（|η_N|=0.048, |η_D|=0.040）的 2 倍——"数据变好"的相对杠杆大于"做大/做多"。

### p32 — Q3 最优性验证（KKT 等边际 + 邻域扰动）

**方法**：完全复刻 p8 模型与成本函数，对 90 组最优解做三类检验（不改任何求解结果，纯验证）。

**量化结果**：

| 检验 | 结果 | 阈值 |
|---|---|---|
| 可行性（C_used ≤ C） | 100% 通过 | =100% |
| 预算占用 | 中位数 100.0000%（精确用满） | ≥99.9% |
| KKT 等边际（11 组内部解） | rel_dev max **0.00%** | ≤5% |
| 边界方向（floor: m_Q≤λ; ceiling: m_Q≥λ） | 100% 正确 | =100% |
| 邻域扰动（200 次/组, lnN±5%, Q±0.02） | 改进率 **0.000%**，max 改进 2e-12 | ≤1% |

**结论**：L-BFGS-B 多起点解满足 KKT 等边际条件至机器精度，邻域内无可行改进——"带约束非线性规划+多初值即可，不需要遗传算法"（第二套提示词判断）得到正式验证。附带发现：90 组中 79 组为边界解（质量在下限/上限），仅 11 组内部解——结构性转移叙事（质量分阶段进入内部解）与优化几何一致。

### p33 — Q4 前沿预测升级（高分位回归 + 滚动回测 + 偏差校正合成）

**方法**：
- τ=0.9 面板分位回归：Average ~ log10N + t（开源 2320 模型）。
- 滚动回测：扩展窗 4 起点（训练 ≥6 月 → 预测下月），三条时序腿（平台/趋势/分位）RMSE 与均值偏差；80% 分位带覆盖率。
- v3 合成：四腿（平台/趋势/分位 + v2 机制腿），回测逆方差权重 + 腿偏差校正，logit 空间有界 90% CI。

**量化结果**：

| 量 | 结果 |
|---|---|
| 腿 RMSE（1 步回测） | 平台 0.976 < 趋势 2.366 < 分位 4.403 |
| 腿偏差（ME） | 平台 −0.72；趋势 +2.24；分位 +3.33（外推过冲被量化并校正） |
| 80% 分位带覆盖率 | 75%（3/4，小样本） |
| 12mo 点预测 | **49.34** [48.09, 50.59]（v2: 47.79；参考基准 49.1 → **残差 1.31→0.24**） |
| 24mo 点预测 | **51.01** [49.76, 52.26]（v2: 48.07；基准 51.9 → **残差 3.83→0.89**） |
| 合成权重 | plateau 0.61, mechanism 0.26, trend 0.10, quantile 0.03 |

**关键发现**：回测正确识别分位腿外推过冲（τ=0.9 的 t 系数 +1.43/月远超前沿实际增速），其权重被自动压至 3%——回测基础设施的自我纠错能力。v2 报告记录的"平台期叙事保守、12mo 低基准 1.3 分"残余差距，经回测加权+偏差校正后收敛至 0.24 分。

### p34 — 基准测试套件（性能指标 + 测试流程）

**结构**：A. 四问 19 项指标（值/基线/阈值/PASS-WARN-FAIL）；B. 5 项独立健全性检查（不依赖生成脚本自证：经典律参数合理域、配比单纯形、Q_star 值域、桥接斜率方向、预算约束独立复核 90 组）；C. 效率计时。

**结果**：**24/24 PASS，0 WARN，0 FAIL**。全套件运行 <0.2s（指标加载 0.00s + 健全性 0.01s + 日志解析 0.14s），可随时重跑作为回归测试。
